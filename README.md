# Зона Ремонта · 05auto.ru

Сайт мастерской ГБО в Махачкале. Сервер отдаёт HTML, контакты, журнал и калькулятор. Редактор цен доступен по адресу `/admin/`. Клиенты звонят или переходят в WhatsApp. Исходная версия сайта в ChatGPT Sites — 11, коммит `9860113d6c26bf1ae633c8e2ded230efaf6e00a2`.

## Сборка и запуск

Используйте Node.js 24 LTS с модулем `node:sqlite`. В архиве уже есть готовая сборка и локальные шрифты. Для её запуска установка пакетов не требуется. При работе из GitHub сначала выполните следующие команды.

```sh
npm ci
npm run build
npm run check
npm run check:hosting
```

Результат сборки находится в `dist/server/index.js`. Этот модуль также содержит все ресурсы. Идентичные изображения, шрифты, стили и скрипты лежат в `dist/client/a/` и могут отдаваться веб-сервером напрямую.

Перед первым стартом задайте `ZR_DATA_DIR` под учётной записью приложения. Один раз выполните `node scripts/setup-admin.mjs` в закрытом терминале. Команда выдаст логин и случайный пароль. В каталоге данных сохраняется только хеш. Чтобы сохранить действующий пароль редактора, используйте в Bash `read -rs -p 'Пароль редактора: ' zr_pw; echo; printf '%s' "$zr_pw" | node scripts/setup-admin.mjs --stdin; unset zr_pw`. Уже настроенный файл хеша защищён от перезаписи. Если хеш передаёт менеджер секретов, задайте `ZR_ADMIN_PASSWORD_HASH` вместо инициализации файла. При переносе используйте новую сессию входа.

Запуск — `node app.cjs`. По умолчанию приложение слушает `127.0.0.1:3105`, формирует канонические адреса на `https://05auto.ru` и создаёт SQLite в `~/.local/share/zonaremonta-05auto/`. Переменные `HOST`, `PORT`, `PUBLIC_ORIGIN` и `ZR_DATA_DIR` переопределяют эти значения. Частный файл для параметров можно указать через `ZR_ENV_FILE`, по умолчанию читается `~/.config/zonaremonta/05auto.env` при его наличии. Исключите каталоги конфигурации и данных из публичного каталога веб-сервера.

## Данные и перенос на Beget

Первый запуск применяет SQL-миграции и переносит открытые данные опубликованной версии. На 20 ноября 2026 года в таблице изменённых администратором цен записей не было, прайс берётся из исходников. Начальные датированные цены топлива хранятся в `hosting/public-seed.json`. Повторный запуск сохраняет изменения. Перед фактическим переключением сверяйте актуальный прайс и сведения о топливе с действующим сайтом.

1. В панели Beget определите сервер, корневой каталог и базу действующего **05auto.ru**. Сохраните файлы сайта, загруженные файлы, конфигурацию веб-сервера и приватные настройки в закрытой резервной копии. При проверке 20 ноября 2026 года по HTTPS на 05auto.ru открывалась страница WordPress «Привет, мир!». Скопируйте весь корень WordPress вместе с `wp-content`, `wp-config.php` и `.htaccess`. Сделайте дамп используемой им базы MySQL/MariaDB через панель Beget или `wp db export` в закрытую папку за пределами сайта. Проверьте чтение архива, восстановите копию файлов и дамп в отдельную тестовую базу. Зафиксируйте текущую привязку домена и конфигурацию HTTPS для отката. У старой страницы встречаются ссылки на другой домен, поэтому при общем каталоге переключайте только привязку 05auto.ru.
2. Разверните новый релиз в отдельном каталоге. Постоянную SQLite и файл хеша разместите за пределами релиза. Для VDS подготовлены `hosting/zonaremonta.service` и `hosting/nginx.locations.conf`. Примеры предполагают каталог `/srv/zonaremonta/current`, отдельного системного пользователя `zonaremonta` и `/usr/bin/node` версии 24. Для первого запуска создайте `/var/lib/zonaremonta` с владельцем службы и правами 0700, затем выполните инициализацию администратора от этого пользователя с тем же `ZR_DATA_DIR`. Для панели с Passenger укажите установленный Node 24, корень приложения, тип `node` и файл запуска `app.cjs`. Публичный корень указывает только на `dist/client/`. Параметры учётной записи, пути и версию Node проверьте на своём тарифе.
3. Протестируйте новый процесс до изменения привязки. При действующем сертификате используйте `curl --resolve 05auto.ru:443:АДРЕС_НОВОГО_СЕРВЕРА https://05auto.ru/` и так же проверьте `/sitemap.xml`, `/ceny/`, `/kontakty/`, `/kalkulyator/` и `/admin/`. Включайте `ZR_TRUST_LOCAL_PROXY=1` только за локальным прокси, который сам устанавливает `X-Real-IP`.
4. После проверки резервной копии направьте HTTPS для **05auto.ru** на новый релиз. Если сервер и IP прежние, достаточно переключить виртуальный хост. Сохраните действующий сертификат и настройки его продления. При смене IP проверьте обе записи A и AAAA. Проверьте публичный сертификат, локальные фото и шрифты, звонок и WhatsApp, расчёт и авторизацию в редакторе. Убедитесь, что значение цены после сохранения доступно на публичной странице. Для отката верните предыдущую привязку и конфигурацию веб-сервера. При восстановлении данных учитывайте записи после момента переключения.

## Обновление топлива и конфиденциальность

В планировщике хостинга поставьте ежедневный GET к `https://05auto.ru/api/toplivo/` на 10:00 по Москве (07:00 UTC). Команда `curl -fsS --max-time 60 https://05auto.ru/api/toplivo/ >/dev/null` запускает проверку открытых источников. Калькулятор также проверяет срок обновления при открытии. При недоступности источников отображается последнее датированное значение. Старое расписание Sites при переносе проверьте отдельно.

Яндекс Метрика по умолчанию выключена. После проверки размещения сервера, журналов и копий в России владелец может задать `ZR_RF_ORIGIN=https://05auto.ru`, `ZR_OPERATOR_NAME`, `ZR_OPERATOR_ADDRESS` и `ZR_METRIKA_ID`. Текущая реализация запрашивает отдельное согласие. Приложение не переносит сессии редактора и идентификаторы согласий между доменами. Запись через MCP на исходной площадке привязана к удостоверенной платформой личности владельца. На Beget публичный HTTP-запрос не получает таких полномочий.

Документация Beget по [Node.js и Passenger](https://beget.com/ru/kb/how-to/web-apps/node-js) и [резервному копированию](https://beget.com/ru/kb/manual/backup).
